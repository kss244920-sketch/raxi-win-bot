# Raxi Win / Raxi4 Auto-Register Telegram Bot

Telegram Bot wrapper for Raxi4, Raxi Win, and AR-SAAS clone sites auto-registration.

## Features
- Dynamic referral link auto-detection & invite code extraction
- VITE_API_URL and AR-SAAS platform discovery
- Single & multi-registration workflow with automated captcha bypass
- Dynamic proxy rotation, validation, and auto-scraping engine
- Admin management suite with token quotas, logs, and channel delivery

## Setup & Running
```bash
pip install -r requirements.txt
python3 raxi4_bot.py
```
